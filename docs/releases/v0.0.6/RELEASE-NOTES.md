# Clash_Mac_Compile v0.0.6 · 已撤回的签名方案草案

> 本文档仅保留开发历史。v0.0.6 的 Developer ID / provisioning / notarization 方案未作为正式可用版本发布；用户没有 Apple Developer 证书，因此该方案已在 v0.0.7 撤回。

v0.0.7 起，项目统一采用无签名构建，不要求 Apple Developer Program 或任何 Apple 证书。

无签名 APP 可以编译并上传 GitHub Releases，但不能保证 macOS VPN / Packet Tunnel 系统授权成功。请阅读当前版本 Release Notes 中的安装限制。
