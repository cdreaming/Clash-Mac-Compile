# v0.1.2 Release Lesson

- Artifact action 报 `No files were found` 只证明配置的路径不存在，不能直接推断 Xcode build 成功或失败。
- 构建脚本应打印规范化的绝对输出目录。
- Build 成功后应自行验证所有必需文件存在且非空，并生成输出 manifest。
- GitHub Build workflow 优先上传一个明确的输出目录，减少多路径 glob 与根目录推导歧义。
- Build / Release / Weekly 显式固定 unsigned 模式，避免 ZIP 命名受 runner 环境影响。
- Release attachment 应校验 APP ZIP 名称与 Build Output Manifest 一致。
