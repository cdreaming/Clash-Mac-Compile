# v0.0.1 Release Lesson

## 本版目标

交付可由 Sourcetree 上传、由 GitHub Actions 自动构建 ProjectClash 原生 macOS APP 的项目源码。

## 事故 / 风险

尚无真实云端构建事故。已识别的主要风险是 Client 主分支移动、Xcode Runner 预览状态、首次 SDK 构建耗时，以及无签名产物的系统权限限制。

## 根因 / 触发条件

Client 源码目前按 commit 更新而非固定 Release tag；若持续使用 `main`，同一项目版本在不同日期可能构建出不同源码。

## 修复 / 决策

构建时记录实际 Client SHA；正式 Release 强制 `UPSTREAM_CLIENT_REF` 为 40 位 SHA。Kernel / Adapter 使用 Client 的依赖锁。

## 防回归规则

正式 Release workflow 执行 `python3 scripts/check-build-config.py --release`，当上游 ref 是 `main` 等可移动分支时立即失败。
