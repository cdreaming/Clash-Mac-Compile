# v0.0.7 Release Lesson

- 用户没有 Apple Developer 证书时，不要强制依赖签名、公证或 Provisioning Profile。
- `CODE_SIGNING_ALLOWED=NO` 明确表示无签名构建，不能宣称 APP 已获得 Network Extension / Packet Tunnel 权限。
- APP ZIP 必须显式标记 unsigned。
- 构建元数据必须写明 `distribution_mode=unsigned` 和 `vpn_authorization_supported=false`。
- Build、Release、Weekly 工作流不得读取 Apple Developer Secrets。
- 只有真实 GitHub Actions 结果才能证明云端 APP 构建成功。
