# v0.1.0 Release Lesson

- 用户实机检查证实 APP 与 Packet Tunnel extension 均为 Ad-hoc 签名，Team ID 未设置。
- 直接分发 macOS Packet Tunnel 不应继续使用 App Extension；根据 Apple TN3134 应采用 System Extension。
- XcodeGen `system-extension` target 必须嵌入 `Contents/Library/SystemExtensions`。
- 主 APP 必须使用 `com.apple.developer.system-extension.install`，APP 与 provider 使用 `packet-tunnel-provider-systemextension`。
- `OSSystemExtensionRequest` 激活应先于 `NETunnelProviderManager` / VPN preference 保存流程。
- 自签名只验证本地代码签名机制，不授予 Apple Developer ID、Team ID 或 Network Extension entitlement。
- 没有 Apple Developer 授权时，GitHub unsigned 构建不得宣称 VPN 已可用。
