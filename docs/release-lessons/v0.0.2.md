# v0.0.2 Release Lesson

## 问题

v0.0.1 Release 在 0 秒内被 `check-build-config.py --release` 拦截。

## 根因

`UPSTREAM_CLIENT_REF` 为 `main`，不是不可变源码引用。

## 修复

将上游 Client 固定为 `e3e647283b1593a61dba622f13cd499deeda9b8b`，并把 Go toolchain 同步到 1.26.10。保留 Release 的 40 位 SHA 安全检查。

## 防回归

- 正式 Release 前执行 `python3 scripts/check-build-config.py --release`。
- 不允许使用 `main` 或其他可移动分支。
- 上游升级必须审查 Client README 和 `Dependencies.lock.json`，并提升本项目版本。

## 遗留边界

GitHub macOS Runner、Xcode 编译、签名、公证和 VPN 实机测试待用户推送后验证。
