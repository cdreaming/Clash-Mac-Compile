# v0.0.3 Release Lesson

## 触发问题

v0.0.2 在 `ClashmacOSExtension` 的 SwiftCompile 阶段编译 arm64 与 x86_64，最终出现 `The operation was canceled`。当前日志不足以确定最初取消原因。

## 决策

先采用 arm64-only 构建和有限并行任务，降低 Runner 的编译资源需求；不关闭 Swift 并发诊断。

## 防回归规则

- `scripts/check-build-config.py` 强制检查 `ARCHS=arm64`、`ONLY_ACTIVE_ARCH=YES`、Xcode jobs 限制和 arm64 Artifact。
- Build workflow 不得配置 `cancel-in-progress: true`。
- APP 主程序必须通过 `lipo -verify_arch arm64`。
- 如需重新支持 Intel，必须先创建新版本并明确评估 Runner 资源。

## 遗留边界

真实 Runner 构建、签名、公证和 VPN 实机测试仍需用户在 GitHub / Mac 上验证。
