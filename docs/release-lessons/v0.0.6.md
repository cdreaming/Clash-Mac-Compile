# v0.0.6 Release Lesson · Withdrawn

- 不要把 Apple Developer 证书作为用户未提供的默认前提。
- 无签名构建可以证明 Xcode 编译成功，但不代表 Network Extension / Packet Tunnel 可以获得系统授权。
- v0.0.7 起移除 Apple signing / provisioning / notarization scripts、secrets 和 workflow steps。
- GitHub Releases 可以发布无签名 APP，但必须在下载说明和 metadata 中明确 VPN 限制。
