# v0.1.5 Release Lesson

- `set -u` 下，变量名只差 `_SPEC` 也会让构建脚本立即退出；声明与引用必须自动化核对。
- `printf` 格式中两个反斜杠会输出字面 `\n`，状态文件解析应验证每个 key/value 独占一行。
- EXIT trap 可通过 `trap 'cleanup_build "$?"' EXIT` 显式传入原始退出码。
- 应测试 cleanup function 在 exit code 65 等非零退出时写入 `status=failed` 和原始退出码。
- Xcode 尚未启动的 Shell 错误不能误判为 Xcode 编译或签名问题。
