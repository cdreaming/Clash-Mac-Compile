# v0.0.9 Release Lesson

## 本版目标
修复 GitHub Release 附件阶段因 BUILD-METADATA.json 尾部字面量 `\\n` 而报 JSON `Extra data` 的问题。

## 事故 / 根因
APP 构建成功，元数据写入器在 JSON 对象后附加了反斜杠和字母 n，而不是实际换行。`json.loads` 因多余字符拒绝解析。

## 修复 / 决策
- 写入器改用真实换行。
- Xcode 版本字段改为处理实际换行。
- JSON loader 增加文件路径、行列和字符位置诊断。
- 新增实际执行 metadata writer 并严格解析输出的回归测试。
- 按每次修改递增版本规则，v0.0.9 修复 v0.0.8 Release 问题，不复用已触发的 v0.0.8 tag。

## 防回归规则
- JSON 生成器必须在测试中实际运行并由严格 parser 重新读取。
- 不允许以静态文本检查代替 JSON 序列化结果验证。
- 本地 P12 / 私钥不进入源码 ZIP。
- GitHub Release workflow 仍只发布 unsigned APP。

## 验证
详见 `docs/releases/v0.0.9/VALIDATION-REPORT.md`。

## 遗留边界
GitHub macOS Runner 和在线 Release 资产仍需用户上传后验证。
