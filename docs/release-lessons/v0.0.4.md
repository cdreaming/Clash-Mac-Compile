# v0.0.4 Release Lesson

## 问题

Xcode 输出 `** BUILD SUCCEEDED **`，但 GitHub Actions 随后失败，错误为 `lipo: -verify_arch requires exactly one input file`。

## 根因

Xcode 27 的 lipo `-verify_arch` 参数顺序不兼容旧调用方式。构建本身已成功，失败位于后置架构检查。

## 修复

移除旧式 `lipo -verify_arch` 调用，改用 `lipo -archs <binary>` 获取架构并断言结果为 `arm64`。同时检查 `CFBundleExecutable` 和文件路径。

## 防回归

- 项目配置检查器拒绝重新引入 `lipo -verify_arch`。
- 项目测试检查使用 `lipo -archs`。
- 架构验证失败时输出主程序路径和实际架构。

## 遗留边界

真实 Xcode 27.1 云端构建、APP Artifact、签名和 VPN 实机测试待 GitHub Actions 验证。
