# v0.0.5 Release Lesson

- 用户的首要体验指标是运行速度与 UI 流畅度，因此 Swift Release 使用 `-O`；是否更快必须通过 Instruments 实测。
- 不要把无签名构建的预期 App Group 路径说成一定存在；必须读取真实签名 entitlement。
- Weekly Preview 只在上游 Client SHA 变化时递增 Patch 并构建；没有变化就跳过。
- 使用 GITHUB_TOKEN 推送的事件不会触发新的普通 push/tag workflow；周度 workflow 必须在同一次运行内完成构建、tag 和 Release。
- Release 页面必须包含清楚的 APP / source ZIP 下载说明、安装限制和配置路径。
