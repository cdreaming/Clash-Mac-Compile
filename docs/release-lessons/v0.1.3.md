# v0.1.3 Release Lesson

- Artifact 验证器报告多个文件缺失时，首先检查构建 step 是否运行、退出码和输出目录，而不是继续改文件名。
- 将 build 和 verify 合并到同一个 GitHub Actions step，避免步骤条件或工作目录差异。
- 使用 `${{ github.workspace }}` 构造绝对输出路径。
- workflow 和 build script 分别持久化 status / exit code / context。
- always-run 报告步骤应打印 step outcome 和实际目录文件清单。
- Release 附件必须要求 build script status=success 且 exit_code=0。
