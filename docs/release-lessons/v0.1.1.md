# v0.1.1 Release Lesson

- v0.1.0 只提供了 Xcode `Ld` 失败摘要，缺少 `ld:` 错误行，因此不能据此臆测 undefined symbol 或 framework not found 的具体原因。
- 从 `.appex` 迁移到更深的 `.systemextension` bundle 后，动态 Framework 的嵌入位置和 `LD_RUNPATH_SEARCH_PATHS` 必须重新核对。
- System Extension 应将其运行时需要的 `ClashMacCore.framework` 嵌入自身 `Contents/Frameworks`，runpath 指向 `@executable_path/../Frameworks`。
- Xcode build 必须保留 verbose log、失败 exit code、target Build Settings 和 XcodeGen spec。
- GitHub Actions 应通过 `if: always()` 上传诊断 Artifact，确保失败后仍能下载日志。
- 静态检查通过不等于真实 Xcode Link 已通过；必须在 xcode-27 Runner 实测。
