# Template Evolution

## 两类经验

项目专用经验留在当前项目 Release Lesson；跨项目仍成立的规则属于模板经验。

典型模板经验：发布证据不能伪造、结构树必须同步、长任务可恢复、私库不能依赖匿名验证、确定性打包等。

## 收尾检查

每版 `RELEASE-EXPERIENCE-REPORT.md` 必须回答：

- 是否发现通用经验；
- 改了哪些模板文件；
- 新增什么自动检查；
- 是否提升 `TEMPLATE_VERSION`。

## 模板版本建议

- patch：文字/小门禁修复；
- minor：新增可复用流程、脚本或测试能力；
- major：改变模板目录、交接契约或发布状态机。
