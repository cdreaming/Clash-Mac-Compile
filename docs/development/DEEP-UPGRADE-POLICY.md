# Deep Upgrade Policy

深度升级指改变架构、数据、权限、安装方式、依赖、协议或发布模型的升级。

## 触发条件

- 主版本变化；
- schema / 数据格式变化；
- 配置不向后兼容；
- 安装路径或服务模型变化；
- 权限/凭据边界变化；
- 核心依赖大版本变化；
- 卸载行为变化；
- Release 资产格式变化。

## 必须覆盖

- 当前架构 / 目标架构；
- 兼容矩阵；
- 数据与配置迁移；
- 回滚；
- fresh install；
- 旧版本 → 新版本；
- 重复升级；
- 卸载；
- 故障注入；
- 安全影响；
- 用户迁移说明；
- 明确不支持边界。
